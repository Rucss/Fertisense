FertiSense | AgTech Soil Analytics Dashboard

FertiSense is a real-time AgTech soil health analytics platform designed to bridge raw environmental sensor telemetry with actionable crop care recommendations. By ingesting real-time pH and Total Dissolved Solids (TDS) measurements, FertiSense eliminates complex data interpretation for growers, delivering an intuitive, high-utility decision-making interface.

Key Features

Real-Time Telemetry Visualization: Live monitoring of soil pH and TDS metrics with high-contrast data charts.

Automated Crop Guidance: Instant translation of chemical readings into actionable nutrient recommendations.

Anomaly & Threshold Alerting: Visual status indicators that highlight soil imbalances before yield is impacted.

Responsive SaaS Interface: Modern, clean dashboard architecture optimized for desktop and tablet field use.

Tech Stack & Architecture

Frontend: React.js, Vite, Tailwind CSS, Framer Motion

API Integration: Axios

Design & Prototyping: Figma

Getting Started

Prerequisites

Node.js (v18.0.0 or higher)

npm or yarn

Installation & Setup

Clone the repository:

git clone https://github.com/meetpatel35/fertisense.git
cd fertisense


Install dependencies:

npm install


Run the development server:

npm run dev


Build for production:

npm run build
