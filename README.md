# Fertisense

## Requirements

Install Node.js 22.12 or newer and npm.

## Available scripts

- `npm install` installs dependencies.
- `npm start` starts the Vite development server at `http://localhost:3000`.
- `npm test` runs the Vitest test suite once.
- `npm run build` creates a production build in `dist`.

The backend runs separately from the frontend. The fertilizer check currently
connects to `http://localhost:5000`.
